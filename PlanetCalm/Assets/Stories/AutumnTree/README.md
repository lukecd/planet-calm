# Autumn Tree app assets

## SceneV1

`SceneV1/` contains the independently layered paper artwork and deterministic
placement data used by `AutumnTreeSceneView`. The canopy seed is `130363`.
Source-generation evidence and review galleries are intentionally not versioned
with the production app.

## SceneV2

`SceneV2/terrain-adjustments.json` applies the current layout correction over
`SceneV1` without modifying source artwork.
